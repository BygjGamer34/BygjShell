# 💻 BygjShell v1.0

![Version](https://img.shields.io/badge/version-1.0.0-orange)
![Java](https://img.shields.io/badge/language-Java-blue)
![Status](https://img.shields.io/badge/status-active-brightgreen)

**BygjShell** es una terminal de comandos personalizada diseñada para potenciar la productividad. Combina la potencia de los comandos nativos del sistema con una capa de utilidades exclusivas desarrolladas por **BygjSoftware**.

---

## 🔥 Características Principales

* **Integración Total:** Ejecuta cualquier comando nativo de tu sistema operativo (Windows/macOS/Linux) directamente desde BygjShell.
* **Comandos Propios:** Incluye herramientas integradas para información de red, sistema y gestión de tiempo.
* **Alias Dinámicos:** Crea tus propios atajos de comandos con `customCommand` para ahorrar tiempo en tareas repetitivas.
* **Modo Sudo Inteligente:** Alterna el uso de permisos administrativos de forma rápida.

---

## 🛠️ Comandos Incluidos

| Comando | Descripción |
| :--- | :--- |
| `sys` | Muestra información detallada del hardware y sistema. |
| `ip` | Revela tu dirección IP local de forma instantánea. |
| `date` | Fecha y hora exacta del sistema. |
| `sudoMode` | Activa/Desactiva el prefijo de superusuario automáticamente. |
| `customCommand` | Crea un alias personalizado para cualquier comando largo. |
| `listCommands` | Muestra todos tus atajos guardados. |
| `about` | Información sobre el núcleo de BygjShell. |

---

## 🚀 Instalación y Uso

Este proyecto se distribuye como un ejecutable compilado para garantizar la seguridad y el rendimiento del software.

1.  Ve a la sección de [Releases](https://github.com/BygjGamer34/BygjShell/releases).
2.  Descarga el archivo `.jar` (requiere Java instalado).
3.  Ejecuta la terminal con:
    ```bash
    java -jar BygjShell.jar
    ```
